## 후속 디자인 정리 시안 — 현재 미적용

아래 시안은 화면 검증과 빌드를 통과했으나, 검증 중 작업 파일이 수정 전 상태로 되돌아갔습니다. 현재 소스에는 적용되지 않았으며, 동시 작업 여부를 확인하고 있습니다.

- 홈과 검색 결과를 그림자 카드에서 구분선이 있는 기록 목록으로 바꿨습니다.
- 요약 수치 타일을 항목명·값 목록으로 정리하고, 반복되는 ‘패턴’ 배지와 넓은 파스텔 배경을 제거했습니다.
- 작성·수정 화면의 반복 카드 대신 구분선과 여백을 사용합니다. 음식명·메모 입력 테두리와 사진 추가 이름을 표시했습니다.
- 버튼·태그의 둥근 정도를 줄이고 그림자는 팝업에만 사용합니다. 컨디션 선택의 확대 효과와 내비게이션의 유리 효과를 제거했습니다.
- 기존 색상, 최대 464px 모바일 폭, 데스크톱 좌우 여백, 사진 영역의 순서·크기를 유지했습니다.

## 검증

- `node scripts/ux-regression.mjs`: 저장 실패, 날짜·태그·기간·집계, 동기화 상태 등 17개 검증 통과. 기존 색상 유지 결정에 따라 대비 개선용 검증은 제거했습니다.
- `scripts/ux-browser-check.mjs`: 독립된 Chrome 세션에서 저장 실패, 사진 지연·개수 제한·취소, 반복 뒤로가기, 검색, 키보드 조작, 320px 화면 등 기존 22개 검증 통과. 320·390·768·1440px에서 본문·내비게이션·팝업 폭 일치와 가로 넘침도 확인했습니다. 디자인 시안에서는 빈 기록 안내 검증을 추가해 23개를 통과했으나, 현재 소스에는 시안이 적용되지 않았습니다.
- `npm run build`, `git diff --check` 통과.
- 실제 계정의 클라우드 동기화는 이번 검증에 포함하지 않았습니다. 상태 전환은 Firebase를 모의 처리해 확인했으며 화면 검증에서는 Firebase 요청을 차단했습니다.

화면 검증은 Vite 개발 서버와 환경에 설치된 Playwright를 사용합니다. 새 의존성은 추가하지 않았습니다.

```sh
npm run dev -- --host 127.0.0.1 --port 4180
# 다른 터미널에서 실행합니다. Playwright가 패키지로 설치되어 있으면 PLAYWRIGHT_MODULE은 생략합니다.
PLAYWRIGHT_MODULE=/path/to/playwright/index.mjs node scripts/ux-browser-check.mjs
```
